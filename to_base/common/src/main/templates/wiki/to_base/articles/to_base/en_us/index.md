# Introduction
{{"of": "self"}} is a library mod in the {{"of": "to_base:tag / to_base:to_series"}}, required by every other mod in the set. The mod targets recent versions of Minecraft and both Fabric and Neoforge.

{{"of": "self"}} was created by {{"of": "to_base:author / to_base:joshmanisdabomb"}}, starting in early 2026.

The most recent version is {{"template": "mod_recent_version"}}.

# Library
This mod's main purpose is to provide shared code for the other To mods, and will usually be updated alongside other mods.

Other modders are free to use this mod as a library for their own purposes, but it is primarily designed exclusively for the To mods.

## Features
- Support for modding on multiple modloaders; service providers for Fabric and Neoforge.
- "Libraries", a system for registering blocks, items, entities and other objects in one place without needing extra boilerplate code.
- Articles, a data-driven system using a Markdown/JSON hybrid template engine, used by the {{"of": "minecraft:block / to_base:research_desk"}} and the online wiki.
- Data providers for quickly copying over and deleting data and resource assets.
- Various Kotlin helper functions.

# Content
Despite being a library mod, {{"of": "self"}} provides a handful of blocks to use:

- The {{"of": "minecraft:block / to_base:research_desk"}}, which allows players to access the wiki article system in-game.
